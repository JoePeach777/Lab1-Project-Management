# Лабораторная работа №5: Стек, очередь, дек, приоритетная очередь

Реализация базовых линейных структур данных и приоритетной очереди на языке **C++** без использования стандартных контейнеров библиотеки STL (`std::stack`, `std::queue`, `std::deque`, `std::priority_queue`).

## 📋 Вариант 9 — Задания

В рамках работы реализованы 4 структуры данных и решены соответствующие индивидуальные задачи:

1. **Стек (`Stack<T>`):** Реализация на основе динамического массива.
   * *Задача:* Проверка корректности HTML-разметки (поддержка вложенных тегов, атрибутов и самозакрывающихся тегов вида `<br/>`).
2. **Очередь (`Queue<T>`):** Реализация на основе кольцевого буфера с динамическим расширением.
   * *Задача:* Удаление всех чётных элементов из очереди за один проход без использования дополнительных структур данных.
3. **Дек (`Deque<T>`):** Реализация на основе двусвязного списка.
   * *Задача:* Проверка, является ли содержимое дека палиндромом (с сохранением исходных элементов дека после проверки).
4. **Приоритетная очередь (`PriorityQueue<T>`):** Реализация на основе двоичной кучи (`max-heap`).
   * *Задача:* Построение приоритетной очереди из произвольного массива за линейное время $O(n)$ (алгоритм Флойда).

---

## ⚙️ Особенности реализации

* **Управление памятью:** Все классы реализуют корректное освобождение выделенной динамической памяти в деструкторах (отсутствие утечек памяти), а также запрет копирования во избежание двойного освобождения (`double free`).
* **Обработка ошибок:** При попытке извлечения или просмотра элемента из пустой структуры генерируется исключение `std::underflow_error`.
* **Шаблоны:** Все структуры данных реализованы как шаблонные классы (`template <typename T>`), что позволяет использовать их с любыми типами данных.

## 📊 Анализ алгоритмической сложности

| Структура / Алгоритм | Операция | Временная сложность | Пространственная сложность |
| :--- | :--- | :---: | :---: |
| **Stack** (динамический массив) | `push` / `pop` / `top` | $O(1)$ *(амортиз.)* | $O(n)$ |
| **Проверка HTML-тегов** | `checkHtmlTags(html)` | $O(L)$ | $O(L)$ |
| **Queue** (кольцевой буфер) | `enqueue` / `dequeue` / `front` | $O(1)$ *(амортиз.)* | $O(n)$ |
| **Удаление чётных элементов** | `removeEvenFromQueue(q)` | $O(n)$ | $O(1)$ |
| **Deque** (двусвязный список) | `push_front/back` / `pop_front/back` | $O(1)$ | $O(n)$ |
| **Проверка дека на палиндром** | `isDequePalindrome(dq)` | $O(n)$ | $O(n)$ |
| **PriorityQueue** (`max-heap`) | Конструктор из массива | $O(n)$ | $O(n)$ |
| **PriorityQueue** (`max-heap`) | `push` / `pop` | $O(\log n)$ | $O(n)$ |
| **PriorityQueue** (`max-heap`) | `top` | $O(1)$ | $O(n)$ |

*Примечание: $n$ — количество элементов в структуре данных, $L$ — длина входной HTML-строки.*
